# Immersive Photo Moment

## 01 目的

全面写真を、情報表示ではなく**体験の区切り**として使用する。使用箇所は2つに限定する。

1. 推薦 → 神社詳細
2. 参拝前の問い

## 02 推薦 → 神社詳細

推薦結果から、実在する神社の情報へ意識を切り替える画面。

```text
推薦結果 → Immersive Photo Moment → 神社詳細
```

```text
[神社・参道・空の全面写真]

今回ご案内する場所

○○神社
東京都○○区

この神社について、
もう少し詳しく見てみましょう。

[ 神社について見る ]
```

**ルール**

- 推薦理由の長文を置かない
- CTAは1つ
- 本文は3〜5行以内
- 詳細情報は次画面で読ませる

## 03 参拝前の問い

参拝前に一度立ち止まるための画面。

```text
神社詳細 → 参拝前の問い → 経路・参拝
```

```text
[境内・木漏れ日・参道の全面写真]

参拝する前に、
ひとつだけ。

今日ここで、
何を整理したいですか？

[ この問いを持って参拝する ]

あとで振り返る
```

**ルール**

- 回答入力は必須にしない
- 心理・宗教的な断定をしない
- 問いは1つだけ
- CTAは1つまで

## 04 写真

推奨：日中の神社 / 参道 / 鳥居越しの空 / 木漏れ日 / 境内 / 水面 / 石段

避ける：強い暗部処理 / 抽象CG / オーラ / 光線 / 過剰な神秘演出

## 05 表示スタイル

```text
Full Screen Photo + 薄い深藍Overlay + 白文字 + Primary CTA
```

Overlay は深藍を薄く使う。目的は演出ではなく、白文字の可読性確保。

## 06 実装に必要なもの（未充足）

| # | 必要なもの | 状態 |
|---|---|---|
| 1 | 02節用の写真（神社・参道・空）。神社ごとに差し替えるのか、共通の1枚を使うのかの方針 | **無し** |
| 2 | 03節用の写真（境内・木漏れ日・参道） | **無し** |
| 3 | 各写真の**使用権利と出典**。`ios-ui-spec-v2.md` 12節および `docs/mobile/ios-brand-ui-audit.md` A-3 のとおり、架空の建築画像を実在神社の写真として扱わない | 未確認 |
| 4 | 解像度と比率（全面表示のため端末幅の3倍相当が要る）。アプリサイズへの影響も見る | 未定 |
| 5 | Overlay の不透明度。白文字が写真の明るい部分でも AA を満たす値を実測で決める | 未定 |

写真が1枚も無い状態でこの画面を作ると、深藍一色の面に白文字が乗るだけになり、
「体験の区切り」という目的（01節・07節）を果たさない。

## 07 役割

情報を読む画面ではなく、**次の体験へ切り替える画面**として扱う。

## 08 禁止事項

- 全面写真を連続使用しない
- 神社詳細本文を全面写真上に載せない
- 推薦理由を長文表示しない
- CTAを複数置かない
- 「ご縁が決まった」等の断定表現を使わない
- 参拝前の回答を必須入力にしない
