## 環境・範囲

- iPhone 16e Simulator / iOS 26.1 / Expo Go / Xcode 27.2。
- CUAのDevice Hub接続が2回タイムアウトした後、ユーザーの明示許可を受けてXCTestを使用。
- XCTestランナーはリポジトリ外で作成。依存追加、アプリ構造・ルート・API・認証・保存ロジックの変更はない。
- 自動監査は `XCUIAccessibilityAuditTypeAll`。監査APIが完了したことと、指摘がないことは別に集計する。
- 各画面の見出し・ナビゲーションバーをAX階層で照合する。コールド起動のリンクが反映されずホームを繰り返した初回バッチは、各画面の証跡から除外した。

- `components/common/AuthPrompt.tsx`：同じグループ化をiOSのみ解除。ボタンのonPress・モーダルの開閉処理は維持。

Web/Androidには上記の属性変更を適用しない。既存のlightテーマ選択とWebアプリのコードも変更しない。
