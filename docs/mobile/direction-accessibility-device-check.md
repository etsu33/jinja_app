### 重大度

| 重大度 | 基準 | リリース判断 |
| --- | --- | --- |
| P0 | 相談不能、クラッシュ、データ・プライバシー事故 | 必ず停止 |
| P1 | 主要フロー不能、読み上げだけでは完遂不能、拒否後に復帰不能 | 原則停止 |
| P2 | 代替操作は可能だが理解・操作に大きな支障 | 別タスク化して判断 |
| P3 | 軽微な文言、余白、限定的な見た目 | リリース後対応可 |

Android Emulatorでの対話操作ができない環境制約のため、`develop` の `a2f6e25a` で方位関連コンポーネントのソースを直接確認した。**これはTalkBackや実タップ操作の代替ではなく、コード上の明白な不備がないかの一次スクリーニングに限る。**

### 上部の戻るボタン

条件変更画面（`ご縁の神社`ヘッダー）の「← 戻る」を、下記の状態で複数回・複数箇所の座標を変えてタップした。

- 画面を開いた直後（下部タブからの直接遷移、履歴なし）
- ホームの「この相談からご縁を見る」から`router.push`で遷移した直後（履歴ありのはずの経路）
- 画面最上部までスクロールした状態
- キーボード表示中／キーボードを閉じた直後
- 「都道府県から指定」選択後
- 「方位情報を使用しない」選択後
- 推薦結果表示後（同一画面内に結果カードが展開された状態）

いずれの状態・いずれの遷移経路でも「← 戻る」のタップは画面遷移を発生させなかった（8回以上のタップ試行、すべて0/1で不応）。詳細は DIR-DEVICE-20260723-02 を参照。

### 位置情報の再許可

1. `xcrun simctl privacy ... reset location host.exp.Exponent` で権限を未決定へ戻し、「現在地を使用」をタップ → iOS標準の許可ダイアログが表示されることを確認
2. 「許可しない」を選択 → 「現在地を取得できませんでした。」と「駅名・住所から指定する」への代替導線が表示され、相談画面全体はエラーにならないことを確認
3. `xcrun simctl privacy ... grant location host.exp.Exponent`（iOS設定の「このAppの使用中は許可」相当）で再許可
4. 再度「現在地を使用」をタップ → **アプリの再インストールなしに**現在地を再取得し、「現在の出発地点は現在地、確定した位置です。」と表示されることを確認
5. 直前に選択していた都道府県などの手動地点が同時に有効になっていないことを確認（出発地点表示は常に単一）
6. 表示文言に緯度経度・住所・駅名などの個人情報は含まれないことを確認

Expo Goでの許可確認であり、製品版アプリの実端末確認済みとは扱わない。

### 外部地図への遷移・復帰

1. 相談結果から神社詳細（例：護王神社）を開き、「地図で経路を確認する」をタップ
2. 1回のタップでGoogle Maps（Safari内ブラウザ表示）へ遷移することを確認
3. Expo Goへ戻ると、神社詳細の表示状態（スクロール位置・内容）が維持されており、二重起動や画面破損がないことを確認
4. 不正な地図URL・地図アプリ不在時の縮退表示は、故障注入環境がないため対話確認できず、コードレビューのみで判定（下記 DIR-DEVICE-20260723-03、実端末確認待ち）
