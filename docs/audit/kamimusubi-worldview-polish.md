# Kamimusubi Worldview Polish Audit

## 目的

Kamimusubiの体験を「検索」ではなく「相談から意味と出会う体験」として磨くため、Web / Mobile / Backend の文言を監査する。

## 判断軸

- 「検索」ではなく「相談」
- 「神社一覧」ではなく「意味との出会い」
- 「ご利益」ではなく「自分との接点」
- 誕生日・九星・五行・方位は前面に出さず、補助シグナルとして扱う

## 監査対象

- Web表示文言
- Mobile表示文言
- Backend生成文言
- テスト内の期待文言
- docs内のプロダクト説明

- Mobile Home / Concierge の表現調整
