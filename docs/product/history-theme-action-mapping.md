

# History Theme Action Mapping

## 目的

KAMI MUSUBIにおける `history_theme` を、推薦理由で終わらせず、行動・夜の振り返り・変化記録へ接続するための正本である。

```text
history_theme
↓
行動テーマ
↓
参拝 / 行動
↓
夜の振り返り
↓
変化記録
```

本ドキュメントは、推薦結果画面・神社詳細・visit_done・reflection保存の判断基準として利用する。

---

## 基本方針

- 行動は小さくする
- 断定しない
- 結果保証をしない
- 宗教的・心理的に強く誘導しない
- 「参拝しなければならない」ではなく「今日できる小さな行動」として扱う
- 夜の振り返りは、ユーザーが自分の変化を見返すための入口にする

---

## history_theme別 行動テーマ対応表

| history_theme | 行動テーマ | 参拝時の行動例 | 日常行動例 | 夜の振り返り質問 |
|---|---|---|---|---|
| 守り | 土台を整える | 手水・境内で一呼吸置き、今守りたいものを一つだけ思い浮かべる | 固定費・予定・体調など、不安の元を一つだけ確認する | 今日、自分の土台を少し守れたことは何か |
| 静寂 | 情報から距離を置く | 境内でスマホを見ずに3分だけ静かに過ごす | 夜に10分だけ通知を切る | 今日、静かになれた瞬間はあったか |
| 再出発 | 小さな区切りを作る | 鳥居をくぐる前に、手放したいことを一つだけ言葉にする | 明日やることを一つだけ決める | 今日、区切りをつけられたことは何か |
| 復興 | 回復を優先する | 無理に願わず、今の疲れを認める時間にする | 休息・睡眠・食事など、回復行動を一つ選ぶ | 今日、自分を立て直すためにできたことは何か |
| 勝負 | 次の一歩を決める | 参拝前後に、今決めたいことを一つだけ書き出す | 迷っている選択肢を一つ減らす | 今日、前に進むために決めたことは何か |
| 学び | 積み上げる対象を絞る | 今学びたいこと・続けたいことを一つ思い浮かべる | 15分だけ学習・練習・整理を行う | 今日、積み上げたことは何か |
| 縁 | 関係を見直す | 今大切にしたい人や機会を一つ思い浮かべる | 連絡・感謝・距離を置くなど、関係の行動を一つ選ぶ | 今日、大切にしたい縁に対して何ができたか |

# 1. 守り

## 定義

不安やリスクから距離を取り、生活や心の土台を整えるテーマ。

## 行動テーマ

```markdown
- 守る
- 整える
- 安定させる
```

## 参拝時の行動例

```markdown
- 手水のあと、一呼吸置く
- 今守りたいものを一つだけ思い浮かべる
- 不安を全部解決しようとせず、今日守る対象を一つに絞る
```

## 日常行動例

```markdown
- 固定費を一つだけ確認する
- 今日の予定を一つ減らす
- 体調を崩しそうな要因を一つ避ける
- 財布・鍵・予定など、生活の基本を整える
```

## 夜の振り返り質問

```markdown
- 今日、自分の土台を少し守れたことは何か
- 不安を大きくしすぎずに済んだ場面はあったか
- 明日も守りたいものは何か
```

## 保存する変化ログ

```markdown
- protected_item: 守りたいもの
- anxiety_level: 不安の強さ
- grounding_action: 実行した小さな整え行動
```

# 2. 静寂

## 定義

立ち止まり、情報や刺激から距離を置いて、自分の内側を見つめ直すテーマ。

## 行動テーマ

```markdown
- 休む
- 離れる
- 整理する
```

## 参拝時の行動例

```markdown
- 境内でスマホを見ない時間を作る
- 3分だけ立ち止まる
- 願いごとを急いで言葉にしない
```

## 日常行動例

```markdown
- 夜に10分だけ通知を切る
- SNSを見る時間を短くする
- 考えていることを3行だけ書く
- 予定を詰め込みすぎない
```

## 夜の振り返り質問

```markdown
- 今日、静かになれた瞬間はあったか
- 情報から距離を置けた時間はあったか
- いま一番減らしたい刺激は何か
```

## 保存する変化ログ

```markdown
- quiet_time_minutes: 静かに過ごした時間
- noise_source: 距離を置きたい刺激
- reflection_note: 整理できたこと
```

# 3. 再出発

## 定義

区切りをつけ、新しい方向へ進もうとしているテーマ。

## 行動テーマ

```markdown
- 切り替える
- 始める
- 一歩踏み出す
```

## 参拝時の行動例

```markdown
- 鳥居をくぐる前に、手放したいことを一つだけ言葉にする
- 参拝後に、明日やる小さな一歩を決める
- 過去を否定せず、区切る対象だけを決める
```

## 日常行動例

```markdown
- 明日やることを一つだけ決める
- やめることを一つ決める
- 古いメモや予定を一つ整理する
- 新しい行動の開始日を決める
```

## 夜の振り返り質問

```markdown
- 今日、区切りをつけられたことは何か
- 明日から変えたい小さな行動は何か
- まだ抱えすぎているものは何か
```

## 保存する変化ログ

```markdown
- reset_target: 区切りたいこと
- next_step: 次の一歩
- release_note: 手放したいこと
```

---

# 4. 復興

## 定義

失ったエネルギーや自信を、少しずつ取り戻していくテーマ。

## 行動テーマ

```markdown
- 回復する
- 立て直す
- 育て直す
```

## 参拝時の行動例

```markdown
- 無理に願いを強く言葉にしない
- 今疲れていることを認める
- 境内で歩く速度を少し落とす
```

## 日常行動例

```markdown
- 早めに寝る
- 食事を整える
- 予定を一つ減らす
- 自分を責める言葉を一つ減らす
```

## 夜の振り返り質問

```markdown
- 今日、自分を立て直すためにできたことは何か
- 少しでも回復した感覚はあったか
- 明日、自分に無理をさせすぎないために何を減らすか
```

## 保存する変化ログ

```markdown
- recovery_action: 回復のためにしたこと
- energy_level: エネルギーの状態
- reduced_burden: 減らした負担
```

# 5. 勝負

## 定義

決断し、挑戦し、前へ進もうとしているテーマ。

## 行動テーマ

```markdown
- 挑戦する
- 決断する
- 動く
```

## 参拝時の行動例

```markdown
- 今決めたいことを一つだけ書き出す
- 参拝前後で、迷っている選択肢を整理する
- 結果ではなく、今日取れる行動を決める
```

## 日常行動例

```markdown
- 迷っている選択肢を一つ減らす
- 連絡を一件入れる
- 応募・相談・予約など、前に進む行動を一つする
- 決断の期限を決める
```

## 夜の振り返り質問

```markdown
- 今日、前に進むために決めたことは何か
- まだ迷っていることは何か
- 明日、最初に動かす一手は何か
```

## 保存する変化ログ

```markdown
- decision_item: 決めたいこと
- action_taken: 実行した一手
- hesitation_note: まだ迷っていること
```

# 6. 学び

## 定義

知識や経験を積み上げ、成長しようとしているテーマ。

## 行動テーマ

```markdown
- 学ぶ
- 積み上げる
- 鍛える
```

## 参拝時の行動例

```markdown
- 今学びたいことを一つ思い浮かべる
- 続けたい練習や勉強を一つだけ決める
- 完璧な成果より、継続する対象を確認する
```

## 日常行動例

```markdown
- 15分だけ学習する
- ノートを1ページ整理する
- 練習を1セットだけ行う
- 分からないことを一つ調べる
```

## 夜の振り返り質問

```markdown
- 今日、積み上げたことは何か
- 小さくても続けられたことは何か
- 明日も続けたい学びは何か
```

## 保存する変化ログ

```markdown
- learning_topic: 学びたいこと
- practice_minutes: 実行時間
- learned_note: 分かったこと
```

# 7. 縁

## 定義

人・機会・場所とのつながりを見直し、育てていくテーマ。

## 行動テーマ

```markdown
- 出会う
- つながる
- 育てる
```

## 参拝時の行動例

```markdown
- 今大切にしたい人や機会を一つ思い浮かべる
- 無理につながりを増やそうとせず、今ある関係を確認する
- 距離を置きたい関係がある場合も否定しない
```

## 日常行動例

```markdown
- 感謝を一言伝える
- 連絡したい人に短く連絡する
- 無理な関係から少し距離を置く
- 大切にしたい予定を一つ入れる
```

## 夜の振り返り質問

```markdown
- 今日、大切にしたい縁に対して何ができたか
- 近づきたい縁、距離を置きたい縁はあるか
- 今の自分に必要なつながりは何か
```

## 保存する変化ログ

```markdown
- relationship_focus: 大切にしたい縁
- connection_action: 取った行動
- boundary_note: 距離感のメモ
```

# visit_doneとの接続

## 目的

`visit_done` は、参拝完了だけではなく、行動と振り返りへの入口として扱う。

```text
route_open
↓
visit_done
↓
reflection_prompt
↓
reflection_saved
```

## visit_done時に保持したい情報

```markdown
- shrineId
- historyTheme
- threadId
- resultSetId
- visitedAt
- actionTheme
```

## visit_done後に出す導線

```markdown
- 今日の参拝を振り返る
- 今の変化を一言で残す
- 夜にもう一度見返す
```

# reflection保存設計

## 最小保存項目

```ts
type ReflectionLog = {
  id: string;
  userId: string;
  shrineId: number | string;
  threadId?: string | null;
  historyTheme: string;
  actionTheme: string;
  prompt: string;
  answer: string;
  moodBefore?: number | null;
  moodAfter?: number | null;
```

