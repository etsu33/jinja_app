

# ご利益と人生テーマの対応表

## 目的

KAMI MUSUBIでは、ご利益を単なる検索条件として扱わず、ユーザーの現在状態と接続するための入口として扱う。

ご利益はユーザーにとって分かりやすい言葉であり、人生テーマは推薦理由・継続記録・分析に使う意味レイヤーである。

```text
ご利益
↓
人生テーマ（history_theme）
↓
神社固有文脈
↓
行動・振り返り
```

## 前提

MVPでは、既存の `history_theme` 7カテゴリに限定する。

```markdown
- 勝負
- 縁
- 守り
- 再出発
- 学び
- 復興
- 静寂
```

`巡り` / `浄化` / `導き` は将来拡張候補とし、現時点では既存7カテゴリへ寄せて扱う。

## レイヤー定義

| レイヤー | 役割 | 例 |
|---|---|---|
| ご利益 | ユーザーの入口・検索導線 | 金運、仕事運、縁結び |
| 人生テーマ | 状態整理と推薦理由の意味レイヤー | 勝負、守り、再出発 |
| 神社固有文脈 | 神社ごとの歴史・由緒・場所性 | 武神信仰、縁結び、再生 |
| 行動・振り返り | 継続利用と変化記録 | 保存、参拝、再相談 |

## 金運の扱い

金運は、単純に「お金が増える」という意味では扱わない。

KAMI MUSUBIでは、金運を次の3方向へ翻訳する。

```markdown
- 守り: お金の不安を減らし、生活の土台を守る
- 勝負: 収入機会、仕事、商いに向き合う
- 再出発: お金の使い方や働き方を見直す
```

そのため、同じ金運相談でも、ユーザーの状態によって推薦理由は変わる。

```text
金運
↓
不安が強い
↓
守り

金運
↓
仕事や商いを動かしたい
↓
勝負

金運
↓
働き方や使い方を変えたい
↓
再出発
```

## 推薦理由生成との接続方針

推薦理由では、ご利益を結果保証として扱わない。

悪い例:

```text
金運が上がる神社です。
```

良い例:

```text
金運という願いを、今はお金の不安を整え、次の判断を落ち着いて選び直すテーマとして受け取れます。
```

## history_theme分析基盤との整合

PostHogでは、`historyTheme` を使って以下を確認する。

```markdown
- concierge_result_impression
- shrine_detail_transition
- route_open
- premium_preview_click
- save_prompt_view
```

ご利益から人生テーマへの対応表を持つことで、`金運` や `仕事運` などの入口が、最終的にどの `historyTheme` として行動につながるかを分析できる。

## 今後の拡張候補

MVP後に、以下のhistory_theme追加を検討する。

```markdown
- 巡り: 金運、商売繁盛、五穀豊穣、福徳と相性が良い
- 浄化: 厄除け、美容、静寂系の整理と相性が良い
- 導き: 方除け、交通安全、進路相談と相性が良い
```

ただし、現時点ではDB、表示文言、分析、推薦理由の複雑化を避けるため、既存7カテゴリでMVP検証を行う。
