# History Theme Taxonomy

## 目的

KAMI MUSUBIにおける`history_theme`のカテゴリ、意味、役割を定義する。

推薦理由・履歴保存・分析・行動提案・振り返りは、本書で定義する7カテゴリを基準とする。

```text
相談内容
↓
意味変換
↓
history_theme
↓
神社推薦
↓
行動
↓
振り返り
```

---

## 基本原則

- `history_theme`は神社側の意味文脈として扱う
- ユーザーの性格・心理状態・将来を断定するために使用しない
- ご利益と`history_theme`を同一視しない
- 1件の相談に対して、主テーマと補助テーマを持つことを許容する
- 推薦理由・行動提案・振り返りで同じカテゴリ名を使用する
- UI・Backend・Analyticsでカテゴリ名を独自に追加しない

---

## カテゴリ一覧

| history_theme | 定義 | 行動テーマ |
|---|---|---|
| 守り | 不安やリスクから距離を取り、生活や心の土台を整える文脈 | 守る・整える・安定させる |
| 静寂 | 立ち止まり、情報や刺激から距離を置いて内側を見つめ直す文脈 | 休む・離れる・整理する |
| 再出発 | 区切りをつけ、新しい方向へ進もうとする文脈 | 切り替える・始める・一歩踏み出す |
| 復興 | 失ったエネルギーや自信を少しずつ取り戻す文脈 | 回復する・立て直す・育て直す |
| 勝負 | 決断し、挑戦し、前へ進もうとする文脈 | 挑戦する・決断する・動く |
| 学び | 知識や経験を積み上げ、成長しようとする文脈 | 学ぶ・積み上げる・鍛える |
| 縁 | 人・機会・場所とのつながりを見直し、育てる文脈 | 出会う・つながる・育てる |

## 守り

### 定義

不安やリスクから距離を取り、生活や心の土台を整える文脈。

### 相談例

- お金や生活基盤に不安がある
- 健康や安全について気になっている
- 将来への不安を落ち着いて整理したい
- 暮らしや家族を守りたい

### 行動テーマ

- 守る
- 整える
- 安定させる

### 関連しやすいご利益

- 厄除け
- 家内安全
- 金運
- 交通安全
- 健康長寿

## ご利益との責務境界

ご利益は、ユーザーが願いや関心を表現するための入口として扱う。

```text
金運
仕事運
恋愛成就
健康長寿
```

`history_theme`は、相談内容と神社情報を接続する意味文脈として扱う。

```text
守り
静寂
再出発
復興
勝負
学び
縁
```

同じご利益であっても、相談内容によって異なる`history_theme`へ接続する。

```text
金運
+
お金への不安
↓
守り
```

```text
金運
+
事業を伸ばしたい
↓
勝負
```

ご利益から`history_theme`への変換ルールは、`docs/product/meaning-translation-mapping.md`を正本とする。

## 責務境界

### History Theme Taxonomy

本書は、`history_theme`のカテゴリ体系そのものを管理する。

管理対象は以下とする。

- 7カテゴリの名称
- 各カテゴリの定義
- 行動テーマ
- 相談例
- ご利益との概念的な関係

本書では、変換ロジック、物理実装および分析契約は管理しない。

### Meaning Translation Mapping

以下は`docs/product/meaning-translation-mapping.md`を正本とする。

- 相談テーマから`history_theme`への変換
- 相談状態から`history_theme`への変換
- ご利益から`history_theme`への変換
- 神社文脈との接続
- Action・Reflectionへの接続

### システム責務

`history_theme`の生成、保存、推薦への反映および画面への受け渡しは、`docs/core/`配下の正本文書と関連するBackend・Frontend実装およびテストを正本とする。

### Analytics

`history_theme`を利用したEvent、Payload、Property、Funnel、KPIおよび分析方法は、`docs/analytics/`配下の正本文書を参照する。

### Product上の利用範囲

Productでは、`history_theme`を以下の体験で一貫したカテゴリとして利用する。

- Recommendation Reason
- Meaning Card
- Action Suggestion
- Visit
- Reflection
- 履歴表示

カテゴリの判定、変換ロジックおよび物理的な保存処理は、本書では管理しない。
