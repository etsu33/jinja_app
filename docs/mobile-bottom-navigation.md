# Mobile Bottom Navigation 設計方針

## 概要

モバイルアプリのボトムナビゲーションは **5項目固定** とする。
相談（コンシェルジュ）を主導線として中央に配置し、左右対称に補助導線を置く。

---

## タブ構成

| 位置 | タブ名 | ルート | 役割 |
|------|--------|--------|------|
| 1 | ホーム | `/` | アプリの起点。相談入力・ランキング導線 |
| 2 | 記録 | `/goshuin` | 御朱印・参拝記録・お気に入りを束ねるハブ |
| 3 | **相談** | `/concierge` | **主導線**。中央配置・強調表示 |
| 4 | ランキング | `/ranking` | 補助導線。人気神社の閲覧 |
| 5 | マイページ | `/profile` | プロフィール・閲覧履歴・設定 |

---

## アイコン対応表

`MaterialIcons`（`@expo/vector-icons`）を使用する。新規アイコンライブラリは追加しない。

| タブ名 | 非アクティブアイコン | アクティブアイコン | 備考 |
|--------|---------------------|-------------------|------|
| ホーム | `home` | `home` | アクティブ時は `gold` カラー |
| 記録 | `book` | `book` | お気に入りは記録配下のサブ画面として扱う |
| 相談 | `auto-awesome` | `auto-awesome` | 中央・強調。背景を `gold` の円形にする |
| ランキング | `bar-chart` | `bar-chart` | 補助導線のため目立たせすぎない |
| マイページ | `person-outline` | `person` | |

## カラー仕様

`kamimusubiDark` テーマ（`app/theme.ts`）に準拠する。

| 状態 | カラートークン | 用途 |
|------|---------------|------|
| アクティブ | `theme.gold` | アイコン・ラベル |
| 非アクティブ | `theme.navMuted` | アイコン・ラベル |
| バー背景 | `theme.background` | ボトムバー全体 |
| 上枠線 | `theme.borderHeader` | バー上部の区切り線 |
| 相談ボタン背景 | `theme.gold` | 中央の円形ボタン |
| 相談ボタンアイコン | `theme.background` | 反転色 |

---

## 設計上の決定事項

### 相談を中央に置く理由
コンシェルジュ機能がアプリの主価値であるため、最もタップしやすい中央に配置する。
視覚的にも `gold` の円形ボタンで他のタブと差別化する。

### お気に入りを独立タブにしない理由
お気に入りは「記録」のサブ機能と位置づける。
独立タブにするとナビゲーションの重みが均等化し、相談の優位性が薄れるため。

### ランキングを補助導線とする理由
ランキングはコンテンツ発見の補助機能であり、主導線ではない。
`navMuted` カラーを使い、視覚的に相談・ホームより控えめに扱う。
